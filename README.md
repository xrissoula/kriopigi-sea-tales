# Kriopigi Beach Stories

Build a mobile-first interactive field guide website for Kriopigi Beach in Halkidiki, Greece.

Purpose: a place-based environmental interpretation and geospatial storytelling project.

Create a polished working skeleton with:

- a cinematic landing page

- an interactive map section

- field notes/species observations

- oral history section

- conservation section

- snorkeling locations

- sea conditions/weather placeholders

- visitor observation submissions

- modern Mediterranean design aesthetic

- responsive mobile layout

Name the project:

"Kriopigi Shore Guide"

Use placeholder images and sample content for now.
